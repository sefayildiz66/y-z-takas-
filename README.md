# Yüz Takas Stüdyosu

iPhone'da (Safari) doğrudan çalışan yüz değiştirme uygulaması. Fotoğraf → fotoğraf ve fotoğraf → video.
Tüm işlem telefonun içinde yapılır; fotoğraf ve videolar hiçbir sunucuya gönderilmez.

Açmak için: https://sefayildiz66.github.io/y-z-takas-/

Modeller (InSwapper, HyperSwap, ArcFace, SCRFD, GFPGAN, XSeg, BiSeNet) ilk açılışta FaceFusion'ın Hugging Face deposundan indirilir.
InSwapper yalnızca ticari olmayan kullanım için yayınlanmıştır. Başkalarının yüzünü izinsiz kullanmak kişilik ve veri koruma haklarını ihlal edebilir.
